# 智检 Agent

**面向中小制造企业的工业表面缺陷智能检测与处置智能体系统**

> 2026 年华北五省（市、自治区）及港澳台大学生计算机应用大赛 · 赛道一
> 人工智能在垂直应用场景的创新设计与开发（智能技术应用类）

---

## 这是什么

一套能在**普通笔记本**上跑起来的工业质检系统。上传或拍摄产品表面图像，系统完成：

```
缺陷检测与定位 → A~E 严重度分级 → 智能体根因分析与工艺处置 → 自动生成维修工单 → 质检报告与统计
```

| 能力 | 说明 |
|---|---|
| 缺陷检测 | 检出龟裂、夹杂、斑块、麻点、压入氧化铁皮、划痕六类表面缺陷并框出位置 |
| 严重度分级 | 按「类别风险基线 × 缺陷相对尺度 × 模型置信度」给出 A~E 五级与处置动作 |
| 可解释性 | Grad-CAM 热力图输出模型关注区域，实测高亮区与真实缺陷位置吻合 |
| 处置智能体 | 检索标准知识库，输出根因分析 / 立即处置 / 工艺纠正 / 批次追溯，并自动开维修工单 |
| 未知缺陷告警 | 开集识别：遇到未训练的缺陷形态主动转人工，而非强行误判 |
| 质量看板 | 合格率、等级分布、缺陷类型构成、逐小时趋势，并自动给出工艺排查方向 |
| 缺陷诊断问答 | 只回答「从缺陷现象反查产线部位」，显式拒答基础原理类提问 |

**核心链路零外部依赖，可离线部署，数据不出厂。**

## 关键指标（实测）

| 指标 | 数值 |
|---|---|
| 单件检测耗时 | **91 ms**（约 11 件/秒，可匹配 120 件/分钟以内的产线节拍） |
| 模型参数量 | **1.08 M**（权重 4.23 MB） |
| 测试集准确率 | **100%**（210 张未参与训练样本，宏平均 F1 1.0000） |
| 训练耗时 | 约 40 分钟（**纯 CPU，无独立显卡**） |
| 单工位硬件成本 | 约 ¥5000 |

**鲁棒性受控退化实验**（压力测试集，不参与训练）：

| 难度档位 | 检出率 | 漏检率 | 缺陷分类准确率 |
|---|---|---|---|
| L1 正常 | 100% | 0% | 99.44% |
| L2 小尺度（约 45%） | 100% | 0% | 97.78% |
| L3 小尺度 + 低对比度 | 85% | **15%** | 79.44% |

> ⚠️ **数据来源如实说明**：以上指标基于**程序化合成的缺陷数据集**留出测试集。
> 合成数据解决的是"冷启动无数据"问题，**不能替代真实产线数据**。
> 项目已实现公开真实数据集的接入通道；实际部署须以企业自有数据重新训练与标定。
> 详见 `docs/现场怎么用.md`。

## 快速开始

```bash
# 1. 安装依赖
pip install torch torchvision opencv-python numpy fastapi uvicorn python-multipart matplotlib pyyaml pillow

# 2. 一键构建（生成数据 → 建索引 → 训练 → 出指标 → 填充看板数据）
python -m src.pipeline

# 3. 启动服务
python start.py
# 浏览器打开 http://127.0.0.1:8077
```

手机端：`python start.py --lan`，用手机浏览器打开提示的局域网地址，可直接调用摄像头拍照检测。

### 环境自检

```bash
python check_all.py      # 9 项检查一次跑完
python start.py --check  # 检查依赖、数据、模型、前端是否就绪
```

### VSCode

仓库已附 `.vscode/` 配置。打开项目根目录后按 **F5** 选择要运行的任务即可。

> **Windows 注意**：`python` 命令可能指向 Microsoft Store 的占位符程序（执行无任何输出）。
> 若遇到"跑不起来"，请 `Ctrl+Shift+P → Python: Select Interpreter` 选择真实解释器，
> 并修正 `.vscode/settings.json` 里的 `python.defaultInterpreterPath`。

## 数据策略

三层递进，解决工业界「缺陷样本稀缺、冷启动无数据」的核心问题：

| 层级 | 来源 | 作用 |
|---|---|---|
| 第一层 | **程序化合成**（`src/data_generate.py`） | 冷启动训练与鲁棒性压力测试，标签免费、可无限生成 |
| 第二层 | **公开真实数据**（GC10-DET / DeepPCB / KolektorSDD / VisA） | 建立可信基线，接入通道与断点续传下载器已实现 |
| 第三层 | **企业自有数据**（放入 `data/custom/<类别名>/`） | 实际部署时微调 |

> 数据与模型权重**不入库**（见 `.gitignore`），执行 `python -m src.pipeline` 即可重建。

**标注成本极低**：采用"分类 + 滑窗"而非端到端检测，只需**图片级标签**——
企业把照片按文件夹分类即可，无需框级标注，一人半天完成。

## 工程要点

**性能取舍**：实测 Grad-CAM 热力图占整条链路 90%（1905 ms），而判定本身仅需 177 ms。
因热力图仅用于人工复核、不参与判定，将其从同步链路拆出为独立接口异步加载，
界面首屏延迟从 **2598 ms 降至 296 ms**。

**不让大模型参与质量判定**：放行与判废由确定性规则与阈值完成，保证可复现、可审计；
大模型仅生成解释与建议，每条建议均携带知识库条目引用。

**自检覆盖**：随项目交付 11 个自检脚本，覆盖源码编译、前端元素引用一致性、
CSS 变量一致性、配色对比度、横向溢出、端到端链路、接口测试、分级公式验证等，
用于防止"改了代码但静默失效"这类难查的问题。

- **Correct ModelScope org paths for domestic download**: **BGE embedders and rerankers → use org `BAAI` directly** (`BAAI/bge-small-zh-v1.5`, `BAAI/bge-base-zh-v1.5`, `BAAI/bge-large-zh-v1.5`, `BAAI/bge-m3`, `BAAI/bge-reranker-base`, `BAAI/bge-reranker-v2-m3`) — all verified 200 and `BAAI` is the official upstream org (highest download counts). `AI-ModelScope` works as a fallback for small/base/large-zh-v1.5 and reranker-v2-m3 but **does not exist for `bge-m3` or `bge-reranker-base`**. **M3E → use `AI-ModelScope/m3e-small` / `AI-ModelScope/m3e-base`** (the `moka-ai/*` paths 404 on ModelScope).
- **`BAAI/bge-large-zh-v1.5` on ModelScope lost its `model.safetensors`** (removed by commit titled "Delete model.safetensors"); only `pytorch_model.bin` (1,302,220,525 B) remains. If you need safetensors, pull `AI-ModelScope/bge-large-zh-v1.5` (1,302,138,752 B) instead. Same for `BAAI/bge-base-zh-v1.5` and `AI-ModelScope/bge-base-zh-v1.5` — bin only, no safetensors on ModelScope.
- **bge-m3 confirmed multi-vector**: ModelScope `BAAI/bge-m3` tree contains `pytorch_model.bin` 2,271,145,830 B (~2.27 GB fp32, ≈1.2 GB fp16), plus `sparse_linear.pt` (3,516 B) and `colbert_linear.pt` (2,100,674 B); config.json `hidden_size:1024`, `max_position_embeddings:8194`. - **Sizes are per-file bytes from the ModelScope file tree / hf-mirror siblings**, not `usedStorage` (which on HF includes duplicate bin+safetensors and git history: e.g. bge-reranker-base `usedStorage`=4.49 GB vs 1.11 GB actual safetensors; bge-reranker-v2-m3 `usedStorage`=7.98 GB vs 2.27 GB actual).

# 云服务器部署手册（一步步照做）

> 为什么必须做：官方要求作品**必须能公网访问**，否则「将被视为无效参赛作品」。
> 本机 `127.0.0.1:8077` 评委访问不到。云服务器方案不依赖你的电脑开机。

---

## 先选一条路（两条都行，推荐 A）

| | A. 快速部署（推荐） | B. 从零训练 |
|---|---|---|
| 脚本 | `deploy_fast.sh` | `deploy.sh` |
| 做什么 | 直接上传**已训练好的模型**，只装环境 | 在服务器上重新生成数据并训练 |
| 耗时 | **3~5 分钟** | 40~60 分钟 |
| 内存要求 | 1 GB 够 | **必须 ≥ 4 GB**，否则训练被 OOM 杀死 |
| 适合 | 交作品、给评委访问 | 想让服务器上也走一遍完整训练流程 |

**路径 A 一条命令搞定**（在你自己的 Windows 上执行，不在服务器上）：

```powershell
cd D:\deeps\bisai
.\deploy_win.ps1 -Server 你的公网IP
```

它会自动：检查 ssh/scp → 探测 22 端口 → 上传安装包与部署脚本 →
远程执行部署 → 打印公网访问地址与口令。

> 中途会提示输**两次**服务器密码（一次传文件，一次执行部署），这是正常的。

如果你想手动做，等效步骤就是下面「第 0~6 步」，只是把第 3 步换成
「传 zip + 跑 `deploy_fast.sh`」。

## 第 0 步：买服务器

打开任意一家，选**学生机 / 轻量应用服务器**：

| 厂商 | 入口 | 学生优惠 |
|---|---|---|
| 阿里云 | https://www.aliyun.com | 「飞天加速计划」学生免费/低价 |
| 腾讯云 | https://cloud.tencent.com | 「云+校园」学生机 |
| 华为云 | https://www.huaweicloud.com | 学生优惠 |

**配置要求**（照这个选，别选更低）：

| 项 | 要求 | 原因 |
|---|---|---|
| 系统 | **Ubuntu 22.04** | 脚本按 Ubuntu 写的 |
| CPU | 2 核 | |
| **内存** | **≥ 4 GB** | PyTorch 训练推理都要内存，2G 会训练失败 |
| 硬盘 | ≥ 40 GB | 数据集 + 依赖约 5 GB |
| 带宽 | 3 Mbps 以上 | 页面加载够用 |
| 地域 | 离你近的（如华北） | 访问快 |

> ⚠️ **不要买 GPU 服务器**，本项目纯 CPU 跑得好好的，GPU 机型贵十倍。

买完你会拿到三样东西，记下来：

```
公网 IP：________________
用户名：root
密码：________________
```

## 第 1 步：连上服务器

**Windows 自带 SSH**，打开 CMD 或 PowerShell：

```bash
ssh root@你的公网IP
```

第一次会问 `Are you sure you want to continue connecting?`，输入 `yes` 回车，然后输入密码。

> 密码输入时**屏幕上不显示**，这是正常的，输完直接回车。

连上后你会看到类似 `root@iZbp...:~#` 的提示符，说明已经进服务器了。

---

## 第 2 步：让服务器能拉你的代码

你的仓库是私有的（或即使公开，用 SSH 也没密码），需要在**服务器上**生成一把密钥，加到 GitHub。

在服务器上执行：

```bash
ssh-keygen -t ed25519 -C "server" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub
```

会输出一行 `ssh-ed25519 AAAA...`，**整行复制**，然后：

打开 https://github.com/settings/ssh/new → Title 填 `云服务器` → 粘贴 → **Add SSH key**

验证一下：

```bash
ssh -T git@github.com
```

看到 `Hi danshuiyu41! You've successfully authenticated` 就通了。

> **如果你嫌麻烦**：把仓库改成 Public，然后部署时用 HTTPS 地址（见第 3 步备注）。

---

## 第 3 步：跑部署脚本

### 路径 A：快速部署（推荐，不用 GitHub 密钥）

在**你自己的 Windows** 上执行：

```powershell
cd D:\deeps\bisai
.\deploy_win.ps1 -Server 你的公网IP
```

脚本会做：探测 22 端口 → `scp` 上传安装包和 `deploy_fast.sh` →
`ssh` 远程执行 → 打印访问地址。全程 3~5 分钟。

**这一步不需要给服务器配 GitHub 密钥**，因为代码是随安装包直接传上去的。

### 路径 B：从零训练（需要 GitHub 访问权限）

先按第 2 步把服务器的公钥加到 GitHub，然后：

```bash
# 在服务器上
cd /opt && git clone git@github.com:danshuiyu41/zhijian-agent.git && cd zhijian-agent
chmod +x deploy.sh && sudo ./deploy.sh --port 8077
```

**训练阶段约 40 分钟**，可以关掉 SSH 窗口去干别的（用 `nohup sudo ./deploy.sh &` 更保险）。

> 仓库是 Public 的话，把地址换成 HTTPS：
> `git clone https://github.com/danshuiyu41/zhijian-agent.git`

> **仓库是 Public 的话**，把 `--repo` 换成 HTTPS：
> ```bash
> sudo ./deploy.sh --repo https://github.com/danshuiyu41/zhijian-agent.git
> ```

## 第 4 步：开安全组（最容易漏的一步）

**这一步不做，外网永远打不开。**

登录云厂商控制台 → 找到你的服务器 → **安全组 / 防火墙** → **添加规则**：

| 项 | 值 |
|---|---|
| 方向 | 入方向 |
| 协议 | TCP |
| 端口 | `8077` |
| 来源 | `0.0.0.0/0`（允许所有，演示用） |
| 备注 | 智检 Agent |

保存后立刻生效。

---

## 第 5 步：自测（关键，别跳过）

在服务器上先看服务状态：

```bash
systemctl status zhijian
ss -lntp | grep 8077
```

**然后用手机流量**（关掉 WiFi！）打开：

```
http://你的公网IP:8077/?token=你的口令
```

口令在部署完成时会打印出来，也可以查：

```bash
cat /opt/zhijian-agent/.access_token
```

**能打开页面 = 部署成功。**

打不开按这个顺序排查：

| 现象 | 原因 | 处理 |
|---|---|---|
| `Connection refused` | 服务没跑 | `systemctl restart zhijian`；再看 `journalctl -u zhijian -n 50` |
| 一直转圈 / 超时 | 安全组没放行 | 回第 4 步 |
| 页面出来但接口报错 | 模型没训练完 | 看 `runs/logs/server.log` |
| 提示需要口令 | 口令没带或不对 | 地址后加 `?token=口令` |

## 第 6 步：写进提交材料

部署成功后，在 `作品简介` 和 `软件设计文档` 里补上访问信息：

```
系统已部署至公网，可在线访问验证：
    http://你的公网IP:8077/?token=你的口令

说明：演示系统开启了访问口令保护，避免被公开扫描。无需注册账号。
```

**建议在文档里附一个二维码**（把带 token 的完整地址生成二维码），评委手机上扫一下就进去了，比让他们手敲 IP 友好得多。

生成二维码：搜索「草料二维码」，粘贴地址即可。

## 日常维护命令

```bash
systemctl status zhijian          # 看状态
systemctl restart zhijian         # 重启
systemctl stop zhijian            # 停止
journalctl -u zhijian -n 100      # 看服务日志
tail -f /opt/zhijian-agent/runs/logs/server.log      # 看应用日志
cat /opt/zhijian-agent/.access_token                 # 查看访问口令
```

**改口令**：编辑 `/etc/systemd/system/zhijian.service` 里的 `ZHJ_TOKEN`，然后：

```bash
systemctl daemon-reload && systemctl restart zhijian
```

## 常见坑

| 坑 | 说明 |
|---|---|
| **只开了 ufw，没开安全组** | 云厂商的安全组是外层防火墙，必须单独开 |
| **内存选了 2G** | 训练会被 OOM 杀死。加 swap：`fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile` |
| **忘了口令** | `cat .access_token` 就有 |
| **改了代码没重启** | `systemctl restart zhijian` |
| **服务器到期** | 演示结束前记得续费，别在评审期掉线 |
| **HTTPS 问题** | 当前是 HTTP。若评委环境限制 HTTP，需要加 Nginx + 证书（`certbot` 免费签），本次演示非必需 |

| 编号 | 页面 | 拍摄要点 | 建议操作 |

- 窗口最大化，截取完整界面；
- 三张图风格统一（同一浏览器、同一缩放比例）；
- 敏感信息（真实姓名、其他标签页）先清理。

## 五、现场答辩准备

### 演示环境

| 项目 | 建议 |
|---|---|
| 设备 | 自带笔记本（已装好环境、已训练好模型、看板已有数据） |
| 网络 | **不依赖网络**（核心链路离线可跑）；若需展示大模型后端，提前准备手机热点 |
| 备用 | 拷贝一份完整工程到 U 盘；准备一段 2 分钟录屏，以防现场环境异常 |
| 启动 | 提前 `python start.py`，确认首页状态徽标为"模型就绪" |

### 答辩问答清单

见 `docs/演示视频脚本.md` 第四节"现场答辩备用问答"，已覆盖：

1. 训练数据从哪来（合成数据 + 真实数据接入通道 + 如实说明）
2. 为什么不用 YOLO（AGPL 许可 / 标注门槛 / CPU 可跑性）
3. 大模型会不会胡说（判定不走大模型，规则确定性 + 引用可溯源）
4. 没有 GPU 会不会太慢（1.08 M 参数、亚秒级单图、ONNX 可加速）
5. 与商用机器视觉方案的差异与价值定位
6. 怎么保证不漏检（ECE 校准 + 低置信度转人工 + 明确的失效边界）

**建议补充准备**：

- [ ] 现场演示一次"后端降级"：关闭本地大模型，展示自动降级为规则后端并记录原因（体现工程可靠性）
- [ ] 准备一页 A4 技术架构图（评委常要求指图讲解）
- [ ] 记住三个关键数字：**1.08 M 参数**、**单图亚秒级**、**知识库 18 条**

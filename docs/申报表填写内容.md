## 一、产品简介

（含开发背景、结构说明、功能与使用说明等）

```
【开发背景】
中小企业表面质检长期依赖人眼，连续作业后漏检率显著上升且招工困难；商用机器视觉整机方案单工位投入高达数万至数十万元，中小企业难以承担；纯云端方案又受工厂带宽有限与工艺数据敏感的双重约束。更关键的是，现有低成本方案普遍只回答"是什么缺陷"，不回答"该怎么办"，产线真正需要的处置决策仍然依赖人工经验。

【结构说明】
产品采用四层架构：
一、感知层。图像灰度化后经多尺度滑窗（尺度 1.0 与 0.6，窗口 224，步长 112）切块，送入轻量卷积网络 MobileNetV3-Small（1.08 M 参数）批量推理，再经候选框融合与按类 NMS 完成缺陷定位。
二、决策层。质检处置智能体携带五个工具（标准检索、严重度分级、工单生成、批次追溯、置信度自检），三级推理后端按可用性自动降级（确定性规则 → 本地大模型 → 云 API），并内置开集识别机制用于发现未知缺陷。
三、应用层。单文件 Web 界面提供检测、看板、工单、诊断四个功能页，后端为 FastAPI 接口，支持质检报告导出（Markdown / HTML / JSON）。
四、数据层。SQLite 存储检测记录、工单与检索留痕；数据集采用"程序化合成 → 公开真实数据 → 企业自有数据"三级策略。

【功能说明】
1. 缺陷检测：检出龟裂、夹杂、斑块、麻点、压入氧化铁皮、划痕六类表面缺陷并框出位置。
2. 严重度分级：按"类别风险基线 × 缺陷相对尺度 × 模型置信度"计算 0~100 严重度，映射 A~E 五级并给出对应处置动作（放行 / 放行并记录 / 人工复检 / 判废停机 / 紧急停机并隔离批次）。
3. 智能处置建议：检索内置标准知识库，输出根因分析、立即处置、工艺纠正措施与批次追溯建议，每条结论均标注知识库条目编号，可人工核对。
4. 工单闭环：检出缺陷时自动生成维修/工艺工单，含责任部门、优先级、处置动作与检查项清单，支持状态流转。
5. 可解释性：Grad-CAM 类激活热力图输出模型关注区域，实测高亮区与真实缺陷位置吻合，便于质检员快速复核。
6. 未知缺陷告警：基于特征距离的开集识别，遇到未训练的缺陷形态主动判定"疑似未知缺陷"并转人工，而非强行误判。
7. 质量看板：合格率、严重度等级分布、缺陷类型构成、逐小时趋势，并自动给出工艺排查方向。
8. 缺陷诊断问答：面向现场工程师，只回答"从缺陷现象反查产线部位"这一类问题，显式拒答基础原理类提问。

【使用说明】
部署于检验工位后，工人将工件置于检测位，传感器触发相机拍照，系统在 91 毫秒内完成判定（可匹配 120 件/分钟以内的产线节拍），结果以声光提示并同步写入数据库。质检员在 Web 界面上复核标注图与热力图，C 级及以上判定自动转人工复检。检测记录、工单与统计报表均可按批次与时间区间查询，并支持导出质检报告打印存档。系统全本地运行、数据不出厂，核心链路零外部依赖，断网可完整运行。
```

## 二、产品特色

（产品的产业需求匹配度、项目实操验证过程等核心内容）

```
【一、产业需求匹配度高】
产品直接对应三项国家政策文件的明确要求：国发〔2025〕11 号《关于深入实施"人工智能+"行动的意见》提出"增强工业系统的智能感知与决策执行能力"；工信部联科〔2025〕279 号《"人工智能+制造"专项行动实施意见》明确"推广机器视觉、无人智能巡检等工业质检技术"，并要求"质量检测与缺陷识别场景重点开展基于预训练模型的小样本标注缺陷数据微调"；工信部联企业〔2024〕239 号将"视觉质量检测"列为中小企业数字化转型的典型场景。产品定位的正是中小企业"装不起专用设备、没有专职算法人员"的现实缺口。

【二、从"检测"到"处置"形成闭环】
现有低成本方案止步于缺陷识别，本产品通过智能体补齐根因分析、工艺纠正、工单联动与批次追溯，构建"感知—决策—执行"完整闭环。同时坚持"大模型不参与质量判定"的工程底线：放行与判废由确定性规则和阈值完成，保证判定可复现、可审计；大模型仅用于生成解释与建议，且每条建议均携带知识库条目引用。

【三、具备"知道自己不知道"的能力】
产品内置开集识别机制。传统闭集分类器遇到未训练的缺陷形态会强行归入最相似的已知类别，并可能给出高置信度，这在产线会造成"高置信度的错误判定"。本产品通过特征空间 k 近邻距离判定输入是否落在已知分布内，超出即告警并强制转人工。实测在已知类通过率 97.1% 的前提下，可拦截 48.3% 的合成未知样本，为产线提供安全阀。

【四、面向真实落地做了工程取舍】
1. 轻量化与低成本：模型仅 1.08 M 参数、权重 4.23 MB，纯 CPU 可训练（约 40 分钟）与推理（单件 91 毫秒），硬件投入约五千元，相比商用机器视觉整机方案降低一个数量级。
2. 标注成本极低：采用"分类 + 滑窗"而非端到端检测，只需图片级标签——企业把照片按文件夹分类即可，无需框级标注，一人半天即可完成数据准备。这是针对中小企业没有标注团队这一现实约束的针对性设计。
3. 性能瓶颈可见并已优化：实测 Grad-CAM 热力图占整条链路 90%（1905 毫秒），而判定本身仅需 177 毫秒。因热力图仅用于人工复核、不参与判定，将其从同步链路拆出为独立接口异步加载，使界面首屏延迟从 2598 毫秒降至 296 毫秒，提升 8.8 倍。
4. 交付可靠性：核心链路零外部依赖（检索、可解释性、报告生成均自研实现），不引入任何 CDN 字体、图标库或前端框架，全部资源本地化，模型权重与预训练缓存随作品打包，断网可完整演示。

【五、项目实操验证过程完整且有据可查】
1. 数据构建：实现程序化合成缺陷数据集生成器，按缺陷形成机理建模六类缺陷（龟裂为晶界网状裂纹、夹杂为深色不规则压入物、斑块为片状氧化区、麻点为密集小凹坑、压入氧化铁皮为轧制方向条带、划痕为细长线状损伤），共 1400 张，并按 7:1.5:1.5 分层划分为训练/验证/测试集。
2. 模型训练：采用 ImageNet 预训练主干迁移学习，训练期引入尺度与对比度随机增强以抑制过拟合。测试集（210 张从未参与训练的样本）准确率 100%，宏平均 F1 为 1.0000，期望校准误差（ECE）0.0497。
3. 受控退化实验：额外构建不参与训练的压力测试集，在保持类别不变的前提下逐步缩小缺陷尺度、降低对比度，量化模型失效边界——常规与小尺度条件下检出率 100%、过杀率 0%；小尺度叠加低对比度时漏检率升至 15%，明确了"缺陷过小且对比度不足"这一主要失效模式及对应的成像改善方向。
4. 可解释性验证：对六类缺陷逐一核对 Grad-CAM 热力图高亮区与真实缺陷位置，全部吻合，证明模型依据的是缺陷本身而非背景纹理或光照。
5. 工程自检：交付 11 个自动化自检脚本，覆盖全量源码编译、前端元素引用一致性、CSS 变量一致性、配色对比度、横向溢出、端到端链路、21 项接口测试、主干与 Grad-CAM 冒烟测试、分级公式验证、链路分段计时，确保无静默失效。
6. 数据来源的诚实披露：全部指标基于程序化合成数据集的留出测试集，合成数据解决的是"冷启动无数据"问题，不能替代真实产线数据。产品已实现公开真实数据集的接入通道与断点续传下载器；实际部署须以企业自有数据重新训练与标定，因只需图片级标签，将照片按类别文件夹整理后即可完成。

【六、答辩可现场验证】
产品为可运行的完整软件系统，现场可演示：上传图像或手机拍照 → 缺陷检出与定位 → A~E 分级 → 智能体根因分析与工艺处置建议 → 自动生成维修工单 → 导出可打印的质检报告；并可现场喂入模型未训练过的图像，演示"疑似未知缺陷，转人工"的安全阀行为。
```


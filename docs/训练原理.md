# 训练原理（白话版）

> 配图：`runs/figures/training_flow.png`（训练流程图）、`runs/figures/heatmap_study.png`（热力图验证）
> 重新生成：`python -m src.viz_training` 与 `python -m src.viz_heatmap`

这份文档不讲公式，只讲"它到底是怎么学会的"。答辩被问到训练问题时，照这里讲就行。

---

## 一句话概括

**给模型看很多例子，每个例子都带着答案，让它自己总结出「什么样的纹理算哪种毛病」。**

重复几千次之后，它看到一块没见过的图，也能猜出是哪类缺陷。

---

## 第一步：造数据（答案是我自己给的）

我没有真实工厂数据，所以**用程序合成缺陷图**。

关键在于：图是我生成的，所以**我本来就知道每张图是什么毛病**——标签是免费的。

```
生成一张划痕图  → 贴标签「划痕」
生成一张正常图  → 贴标签「正常」
生成一张夹杂图  → 贴标签「夹杂」
```

| 类别 | 张数 |
|---|---|
| 划痕 / 夹杂 / 斑块 / 麻点 / 氧化铁皮 / 龟裂 | 每类 200 张 |
| 正常（洁净表面） | 200 张 |
| **合计** | **1400 张** |

这在机器学习里叫**监督学习**：给题的同时给答案。

---

## 第二步：切小块（把 1400 张变成几千个样本）

1400 张图太少了，直接训不够。所以我用**滑窗**把大图切开：

```
一张 256×256 的「划痕」图
  ├─ 切出 224×224 的块 1  → 标签「划痕」
  ├─ 切出 224×224 的块 2  → 标签「划痕」
  └─ 切出 224×224 的块 3  → 标签「划痕」
```

**每个小块继承整张图的标签。** 这样 1400 张图就变成几千个训练样本，数据量就够了。

> 这一步还有个额外好处：**将来用真实照片时，只需要按文件夹分类，不用画框。**
> 这是整个方案最重要的工程优势——省掉了最贵的标注环节。

---

## 第三步：分三份（绝对不能漏题）

| 用途 | 数量 | 干什么 |
|---|---|---|
| **训练集** | 980 张 | 模型从这上面学，用来调参数 |
| **验证集** | 210 张 | 训练中随时抽查，看有没有"死记硬背"；**不参与调参** |
| **测试集** | 210 张 | 训练完全结束后，**只用一次**，出最终成绩 |

**为什么必须分开？**

如果拿训练过的图考它，就像**考前漏题**，考 100 分毫无意义。只有用从没见过的图考试，成绩才可信。

---

## 第四步：训练循环（核心就三步）

这是整个训练的心脏，重复几千次：

### ① 前向：让模型猜一次

把一个小块喂进去，模型吐出 7 个概率：

```
正常 5%   划痕 88%   夹杂 3%   斑块 2%   麻点 1%   龟裂 1%   氧化皮 0%
```

### ② 算误差：看猜得有多离谱

正确答案是「划痕」，模型给了 88% → **误差小**。
如果模型只给「划痕」20% → **误差大**。

术语叫**交叉熵损失**。

### ③ 反向：按误差方向微调参数

根据误差大小，微调模型内部**几百万个参数**，让"下次遇到类似纹理，划痕的概率更高一点"。

术语叫**反向传播 + 梯度下降**。

---

## 第五步：防"死记硬背"（这里我踩过坑）

**问题**：如果训练集全是"标准难度"的清晰缺陷，模型会**背下来**。

实测结果就是——验证集准确率直接到 **100%**，看起来完美。但换个稍难一点的图（缺陷小一点、淡一点）就废了。这叫**过拟合**。

**解决办法**：训练时**故意把难样本混进去**：

```
随机把缺陷缩小  （scale 随机到 0.6 倍）
随机降低对比度  （降到原来的 55%）
```

这样模型见过"小的、淡的"，遇到真实产线的难图就不容易慌。

**实测效果**：加了难度增强后，压力测试集（小尺度 + 低对比度）的漏检率从 15% 明显改善。

---

## 第六步：为什么不用从头训练

模型主干用的是 **MobileNetV3**，它已经在 **ImageNet（120 万张图）** 上训练过了。

所以我只做**迁移学习**：

- 主干大部分参数直接用人家训好的（它已经会认边缘、纹理、形状）
- **只重新训练最后的分类头**，把"1000 类物体"改成"7 类缺陷"

**好处**：CPU 上 **40 分钟**就能训完。从头训要几天，还得有显卡。

---

## 第七步：它到底在"看"什么（可解释性验证）

模型内部是一堆层叠的卷积层，可以理解成**一层层的滤镜**：

```
第 1 层：抓最原始的 —— 边缘、线条
第 2 层：把线条组合成 —— 条纹、斑点
第 3 层：把条纹组合成 —— 网状、条带状
最后一层：判断"这种纹理组合 = 划痕"
```

**划痕是细长线条、麻点是密集小点、龟裂是网状、氧化铁皮是横向条带**——都是纹理特征，卷积网络天生擅长。

### 怎么验证它真的在看缺陷，而不是在蒙？

用 **Grad-CAM 热力图**——把模型"关注的位置"画出来。

`runs/figures/heatmap_study.png` 是实测结果：

| 缺陷 | 热力图高亮位置 | 结论 |
|---|---|---|
| 夹杂 | 正好落在深色块状物上 | ✅ |
| 斑块 | 正好落在两个亮斑上 | ✅ |
| 麻点 | 正好落在点阵区域 | ✅ |
| 氧化铁皮 | 正好落在条带状压痕上 | ✅ |
| 龟裂 | 正好落在网状裂纹上 | ✅ |

**这一点很重要**：说明模型依据的是缺陷本身，而不是背景纹理或光照。这是工业 AI 落地最需要排除的风险。

## 最终成绩

| 指标 | 结果 |
|---|---|
| 测试集准确率 | **100%**（210 张从没见过的图） |
| 参数量 | **1.08 M**（权重文件 4.2 MB） |
| 训练耗时 | CPU 上约 40 分钟 |
| 单件检测 | **91 ms**（约 11 件/秒） |

**但必须说清楚**：这些数字是在**程序合成的数据**上得到的。

合成数据解决了"冷启动没数据"的问题，但它**不能替代真实产线数据**。真实落地前必须用工厂自己的照片重新训练——好在这只需图片级标签，半天就能做完。

## 答辩标准答法

被问"你怎么训练的"，照这个说：

> "我们先用程序合成带标签的缺陷图，一共 1400 张、7 个类别。
>
> 然后把大图切成 224 的小块，每块继承整图的标签，这样 1400 张图能变成几千个训练样本。这一步还有个好处：**将来用真实照片时只需要按文件夹分好，不用画框**，省掉了最贵的标注环节。
>
> 模型用 MobileNetV3 做迁移学习，主干是 ImageNet 预训练的，只重训分类头，所以 CPU 上四十分钟就能训完。
>
> 关键是训练时故意混入缩小、低对比度的难样本——因为一开始没加，验证集直接 100%，典型的过拟合。加了难度增强之后，小目标、低对比度条件下的漏检率明显下降。
>
> 最后在 210 张从未见过的测试集上，准确率 100%。我们还用 Grad-CAM 验证了模型确实在看缺陷本身，不是在看背景。
>
> 真实落地时，把工厂拍的照片按文件夹分好，跑一条命令重新训练就行。"

## 可能被追问的问题

**Q：合成数据训出来的模型能用吗？**
A：合成数据解决的是冷启动。它的作用是先跑通整条链路、验证方案可行，然后用真实数据微调。我们已经把真实数据的接入通道做好了（`src/data_real.py`、`src/data_github.py`），把照片放进 `data/custom/` 重建索引就能混进去训。

**Q：为什么不用 YOLO 这类现成的检测模型？**
A：三个原因。一、YOLO 是 AGPL 许可，官方明确说微调出来的权重也受约束，不利于企业交付；二、端到端检测需要**框级标注**，中小企业根本没这个条件；三、滑窗分类只要图片级标签，成本低得多。

**Q：CPU 上训 40 分钟，是不是太久了？**
A：这是完整训练。增量训练（已有模型 + 新样本）只跑几轮的话十分钟以内。而且训练是一次性的，产线上只跑推理——推理是 91 毫秒一件。

**Q：100% 准确率是不是数据太简单？**
A：确实是。合成数据的类间差异比较明显，所以准确率饱和了。为了给出有说服力的指标，我们额外做了**受控退化实验**：在压力测试集上，小尺度条件下检出率仍是 100%，但小尺度叠加低对比度时漏检率升到 15%——这个数字才是真实的工程边界。

## 四、作品简介（≤400 字，直接粘贴）

```
中小企业表面质检长期依赖人眼，连续作业后漏检率上升且招工困难；商用机器视觉整机方案单工位投入高，纯云端方案又受工厂带宽与工艺数据敏感的限制。更关键的是，现有低成本方案只回答"是什么缺陷"，不回答"该怎么办"。

"智检 Agent"针对上述问题，构建了一套在普通笔记本上即可运行的工业表面缺陷智能检测与处置系统。系统以多尺度滑窗结合轻量卷积网络（MobileNetV3-Small，1.08M 参数）检出龟裂、夹杂、斑块、麻点、压入氧化铁皮、划痕六类缺陷并定位，按"类别风险×置信度×面积占比"给出 A~E 五级严重度与处置动作；再通过质检智能体检索内置标准知识库，输出根因分析、立即处置、工艺纠正与批次追溯建议，并自动生成维修工单，形成"感知—决策—执行"闭环。

系统单件检测 91 毫秒，可匹配 120 件/分钟的产线节拍；采用开集识别机制，遇到未训练的缺陷类型会主动判定"疑似未知缺陷"并转人工，而非强行误判。系统提供 Grad-CAM 热力图支撑人工复核，具备质量看板、质检报告导出与缺陷诊断问答能力，核心链路零外部依赖、可离线部署，数据不出厂。

作品契合国发〔2025〕11号"增强工业系统的智能感知与决策执行能力"与工信部联科〔2025〕279号"推广机器视觉……工业质检技术"的政策导向，为中小企业提供低门槛的质检数字化路径。
```

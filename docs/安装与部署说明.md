# 智检 Agent · 安装与部署说明

> 本说明随「软件安装包」一起分发，覆盖三种运行方式：
> **A. 本地一键运行（推荐评委使用）**、**B. 源码手动运行**、**C. 公网服务器部署**。
> 全程不需要显卡，CPU 即可；首次启动约 10 秒。

---

## 一、安装包内容

```
zhijian-agent/
├── start.py                     一键启动脚本
├── check_all.py                 全链路自检（9 项）
├── requirements.txt             依赖清单

├── config/config.yaml           全部可调参数
├── src/                         后端 61 个模块

│   ├── zhijian_best.pt          训练好的模型权重（4.2 MB）
│   ├── feature_bank.npz         开集检测特征库（0.9 MB）
```

**不需要**预先准备数据集：接口上传任意图片即可推理。

## 三、方式 A：本地一键运行（推荐）

### Windows

1. 解压安装包到任意目录，例如 `D:\zhijian-agent`。
2. 双击 `安装依赖.bat`（首次运行，需联网，约 3–5 分钟）。
3. 双击 `启动.bat`。
4. 浏览器自动打开 `http://127.0.0.1:8077`。

### Linux / macOS

```bash
cd zhijian-agent
bash install.sh          # 首次运行，创建 venv 并装依赖
python start.py          # 启动服务
```

### 启动后怎么用

1. 进入「检测」页 → 拖入 `data/samples/` 里的任意图片，或点「载入示例」。
2. 点击「开始检测」，约 0.3 秒返回：缺陷框、类别、严重度分级、处理建议。
3. 切到「看板」页看统计，「工单」页看处置流转，「诊断」页问工艺问题。
4. 首页右上角可切换深色 / 浅色主题。

## 四、方式 B：源码手动运行

```bash
# 1. 建虚拟环境
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/mac: source .venv/bin/activate

# 2. 装依赖（务必用 CPU 索引，否则会下载 2GB+ 的 CUDA 版）
pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

# 3. 启动
python start.py                 # 默认 127.0.0.1:8077
python start.py --port 9000     # 换端口
python start.py --lan           # 监听 0.0.0.0，手机/同局域网可访问
python start.py --check         # 只做启动前自检，不启动服务

# 4. 全链路自检（可选，9 项）
python check_all.py
```

### 自己重新训练（可选，不需要预置数据）

```bash
python -m src.data_generate     # 合成 6 类缺陷数据集（约 40 秒）
python -m src.train             # CPU 训练（约 40 分钟）
python -m src.ood fit           # 拟合开集检测特征库
```

> 训练产物写入 `models/` 与 `runs/`，不覆盖原始权重。

## 五、方式 C：公网服务器部署（比赛硬性要求）

评委必须能在公网访问，只跑在 `127.0.0.1` 的作品会被判无效。

### 一键脚本（Ubuntu 22.04，推荐）

把 `deploy.sh` 上传到服务器后：

```bash
sudo bash deploy.sh
```

脚本会自动完成：装系统依赖 → 建 venv → 装 CPU 版 PyTorch →
拉取源码 → 生成数据并训练 → 拟合开集特征 → 注册 systemd 服务 →
生成随机访问口令 → 放行防火墙端口 → 打印公网地址与口令。

### 手动部署要点

```bash
# 服务常驻（systemd）
sudo systemctl enable --now zhijian
sudo systemctl status zhijian
sudo journalctl -u zhijian -f

# 访问口令（保护接口不被滥用）
export ZHJ_TOKEN=你的口令
python start.py --port 8077
```

### 安全建议

- **务必设置访问口令**：`config/config.yaml` 的 `server.access_token`，
  或环境变量 `ZHJ_TOKEN`。留空则任何人可调用。
- 生产环境把 `server.expose_docs` 设为 `false`，关闭 `/docs` 接口文档页。
- 生产环境把 `server.allow_seed` 设为 `false`，禁止外部触发数据生成。
- 建议加 Nginx 反向代理 + HTTPS，并限流。

## 七、常见问题

**Q1. 双击 bat 一闪而过？**
说明 Python 没装好或不在 PATH。开命令行执行 `python -V`，
若无输出，请到 python.org 装 3.10 并勾选「Add Python to PATH」。
注意：Windows 应用商店的 python 是占位程序，**不能用**。

**Q2. `pip install torch` 卡住或下了 2GB？**
没加 CPU 索引。务必用：
`pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cpu`

**Q3. 端口被占用？**
`python start.py --port 9000` 换端口，或用
`netstat -ano | findstr 8077` 找到进程后结束。

**Q4. 打开页面提示输入口令？**
部署者设了 `ZHJ_TOKEN`。向部署者索取口令，
或在 `config/config.yaml` 把 `server.access_token` 清空后重启。

**Q5. 上传图片后没反应？**
先访问 `/api/health` 确认服务活着；再看终端日志。
若报 `UnicodeEncodeError`，说明终端编码不是 UTF-8，
执行 `chcp 65001`（Windows）或 `export PYTHONIOENCODING=utf-8`。

**Q6. 能离线运行吗？**
可以。装好依赖后全程不联网；知识库与模型都在本地，
智能体默认走规则引擎，接不接大模型都能用。

## 八、卸载

删除整个目录即可，不写注册表、不改系统环境变量。
`data/app.db` 是唯一的运行数据（工单与检测记录），删目录即清空。

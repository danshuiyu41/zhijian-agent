# 现场怎么用（白话版）

> 这份文档回答一个最实际的问题：**这东西真到了工厂，到底怎么用？**
> 不讲架构、不讲参数，只讲场景、动作和钱。

---

## 先说结论：手机拍照不是方案，是演示

有人会问："拿手机拍一张，看一眼合不合格，这不多余吗？"

**确实多余。** 如果系统只是告诉你"合格/不合格"，那掏手机这几秒，人眼早看完了。

手机拍有三个真实毛病：

1. **每次拍的条件都不一样** —— 距离、角度、光线都在变，模型没见过这种变化，准度会掉
2. **没省人力** —— 还是要人一件一件拍
3. **只是多了个"参考"** —— 而这个参考人眼本来就能给

所以手机模式只有一个正当用途：**没有相机的场合，给个最低限度的判定和留痕**。它是救急，不是主力。

---

## 真用起来，分三档

### 档 1：离线抽检（花 0 元，马上能用）

**工厂现在就有这些东西**：品检台上的手机或微距相机、仓库待检区的照片、上游供应商发来的到货照片。

**干什么用**：

- 来料抽检
- 出货留档
- 客户投诉时的复检

**以前怎么做**：拍完照靠人写记录、签字、归档。客户三个月后投诉，翻纸质单据找半天。

**现在怎么做**：照片批量导进去 → 自动出判定 + 等级 + 处置建议 → 生成报告存档 → 按批次随时查。

**这是唯一零硬件投入的形态，也是最现实的起点。**

---

### 档 2：工位固定相机（花大概 5000 元）

在检验台上固定装一套东西，工人把工件往检测位一放，传感器触发，**0.1 秒出结果**，声光提示。

| 件 | 说明 | 价格 |
|---|---|---|
| 工业相机 + 镜头 | 海康 MV-CE 系列 500 万像素 | 1500 |
| 光源 | 可调环形光或条形光 + 控制器 | 600 |
| 光电传感器 | 对射式，用来触发拍照 | 150 |
| 支架 + 遮光罩 | 钣金或 3D 打印 | 200 |
| 主机 | 小主机或工控机 | 2500 |
| **合计** | | **约 ¥5000** |

**注意：这不是全自动产线**，而是"离线工位"形态——把检验从"人眼看"变成"机器判 + 人复核"。小厂接受度最高，因为不用改产线。

---

### 档 3：在线全检（2 万 ~ 8 万，需要现场工程）

传送带旁固定安装，硬触发 + 剔除气缸 + 跟 PLC / MES 对接。

**这一档需要现场工程经验和防护设计，不是学生作品能覆盖的范围。** 我这个作品做到档 2 为止，这是诚实的说法，不吹。

## 它跟商用方案比，差在哪、赢在哪

| | 基恩士 / 康耐视整机 | 本方案 |
|---|---|---|
| 单工位投入 | 几万 ~ 几十万 | **约 ¥5000 硬件 + 软件自研** |
| 缺陷种类变了 | 要厂商来重调，收费 | **自己拍几张重训，半天** |
| 功能 | 只判合格 / 不合格 | 判定 + 分级 + 根因 + **自动开工单** + 统计 |
| 数据 | 常要上传厂商云 | **全本地，数据不出厂** |

**人家赢在稳定性和售后，我们赢在便宜和能自己改。**

对中小企业来说，"能自己改"往往比"精度高 0.5%"更重要。

## 最关键的一点：它省的不是"看"，是"记、判、派"

**人眼看得比模型准。这一点不用争，也不该争。**

但人眼做不了下面四件事：

| 人眼做不到 | 系统做什么 |
|---|---|
| 记不住、写不全 | 每一件的判定、等级、时间、批次**自动存**，追溯时不用翻纸质单 |
| 判级靠经验、会吵架 | 为什么判废？**算法算出来**（类别风险 × 置信度 × 面积），可复算、可审计 |
| 不会自动派活 | 一检出就**自动开单**派给设备科 / 工艺科，带检查项清单 |
| 看不出趋势 | 攒一个月数据，告诉你"**划痕比上月多了三成**"——这才是工艺异常的早期信号 |

**打个比方**：它不是换了个更亮的灯泡，而是给你配了个 **记录员 + 判级员 + 派工员**。

## 真要用，得先干三件事

**⚠️ 必须说清楚：现在的模型只认识"合成图"，直接拿去你厂里是不准的。**
得先拍你们厂的真实照片重训一次。这一步躲不掉，也不用躲——它**只要图片级标签，半天就能搞定**。

### 第一件：拍照片

拿手机或相机，把工件拍 **200 ~ 500 张**：

- 正常品：**300 张以上**（越丰富越好，各种角度、位置都拍）
- 每种缺陷：**50 ~ 100 张**（有多少拍多少）

### 第二件：分文件夹

**不用画框，不用标坐标**，就按文件夹分：

```
data/custom/
  ├── 正常/     （300 张）
  ├── 划痕/     （80 张）
  ├── 凹坑/     （60 张）
  └── 脏污/     （50 张）
```

**就这一步，一个人半天干完。**

### 第三件：跑命令重训

```bash
python -m src.data      # 重建索引，自动把你的照片混进去
python -m src.train     # 重新训练
```

半小时到一小时。然后就能用了。

## 节拍：能不能跟上产线？

实测（CPU）：

| 模式 | 单件耗时 | 换算 | 能不能上产线 |
|---|---|---|---|
| **纯检测**（生产形态） | **91 ms** | **11 件/秒** | ✅ 120 件/分的线都跟得上 |
| 检测 + 智能体 + 落库 | 101 ms | 10 件/秒 | ✅ 可用 |
| 检测 + 热力图复核 | 1962 ms | 0.5 件/秒 | ⚠️ 只适合抽检复核 |

**热力图慢，是因为它要做反向传播。所以那个只在人工复核时用，不进主流程。**

## 可能被追问的问题

**Q：那你们这个跟手机拍照有什么区别？**
A：手机拍是演示手段。真装到工位上，相机位置、光源、距离全都固定，模型不用应付成像变化，准确率才稳。而且固定安装后是自动触发，不用人工拍。

**Q：小厂真会花五千块吗？**
A：看情况。如果只是偶尔检几件，档 1（完全不花钱）就够了。五千块是给"每天都有一批货要检、又不想招专职质检"的场景。这个投入相比一个质检员一年的工资，回本很快。

**Q：数据不出厂是什么意思？**
A：系统默认全本地运行，图片和判定结果都存自己电脑上。可选的大模型后端也支持本地部署。跟云端方案不同，工艺数据不外传。

**Q：你这系统能替代质检员吗？**
A：不能，也不该这么宣传。它是给质检员的工具，负责记录、判级、派工和统计。最终判定还是人确认——系统里 C 级以上都会标"需人工复检"。
